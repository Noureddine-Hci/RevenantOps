**ZombieBase.h:**
- `#pragma once`, include `EnemyBase.h`, include `ZombieBase.generated.h`
- `UCLASS(abstract, Blueprintable)` class AZombieBase : public AEnemyBase
- Protected properties:
  - `UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Zombie|Combat")` float MeleeDamage = 10.f (ClampMin 1, ClampMax 200)
  - `UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Zombie|Combat")` float MeleeRange = 150.f (ClampMin 50, ClampMax 500)
  - `UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Zombie|Combat")` float MeleeAttackCooldown = 1.5f (ClampMin 0.1, ClampMax 5.0)
  - `float MeleeAttackTimer = 0.f;` (internal cooldown tracker)
  - `bool bIsAttacking = false;`
- Protected methods:
  - `virtual void BeginPlay() override;`
  - `virtual void Tick(float DeltaTime) override;`
  - `virtual void PerformMeleeAttack();` — virtual so subclasses can override (exploder overrides to explode)
  - `void UpdateZombieCombat(float DeltaTime);` — replaces the gun-based UpdateCombat: if in MeleeRange, call PerformMeleeAttack on cooldown; otherwise MoveToActor the player directly
  - `void MoveDirectlyToPlayer();` — simplified movement: AAIController->MoveToActor(TargetPlayer, MeleeRange * 0.5f) with no behavior profile branching
- Blueprint hooks:
  - `UFUNCTION(BlueprintImplementableEvent, Category = "Zombie|Events")` void BP_OnMeleeAttack();

**ZombieBase.cpp:**
- Include `ZombieBase.h`, `Kismet/GameplayStatics.h`, `AIController.h`, `GameFramework/CharacterMovementComponent.h`, `HealthComponent.h`
- Constructor AZombieBase::AZombieBase():
  - Set BehaviorProfile = EEnemyBehavior::Aggressive (zombies are always aggressive)
  - Set WeaponClass = nullptr (zombies don't use weapons)
  - Set SightRange = 2000.f (zombies detect closer but wider)
  - Set SightHalfAngle = 120.f (wide FOV, zombies are not precise)
  - Set IdealEngagementRange = 100.f (melee range)
  - Set MaxEngagementRange = 100.f
  - Set ReactionTime = 0.2f (zombies react fast, not tactical)
- BeginPlay(): call Super::BeginPlay() only
- Tick(float DeltaTime):
  - Call Super::Tick(DeltaTime) — this runs UpdatePerception from EnemyBase
  - Then call UpdateZombieCombat(DeltaTime)
  - Note: Super::Tick already calls UpdateCombat, but that relies on EquippedWeapon which is null. The FireAtPlayer call in UpdateCombat checks `if (!EquippedWeapon)` and returns. So the gun combat path is effectively disabled. UpdateZombieCombat handles the melee path separately.
- UpdateZombieCombat(float DeltaTime):
  - Early return if AlertState != Alert or TargetPlayer is null
  - Decrement MeleeAttackTimer by DeltaTime, clamp to 0
  - Calculate distance to TargetPlayer: FVector::Dist(GetActorLocation(), TargetPlayer->GetActorLocation())
  - If distance <= MeleeRange and MeleeAttackTimer <= 0:
    - Call PerformMeleeAttack()
    - Set MeleeAttackTimer = MeleeAttackCooldown
    - Set bIsAttacking = true (reset to false next tick if distance > MeleeRange)
  - Else: call MoveDirectlyToPlayer(), set bIsAttacking = false
- PerformMeleeAttack():
  - Guard: if (!TargetPlayer) return
  - Apply damage: UGameplayStatics::ApplyDamage(TargetPlayer, MeleeDamage, GetController(), this, nullptr)
  - Call BP_OnMeleeAttack()
- MoveDirectlyToPlayer():
  - Guard: if (!TargetPlayer) return
  - Get AAIController* AIC = Cast of GetController()
  - If AIC: AIC->MoveToActor(TargetPlayer, MeleeRange * 0.5f)

IMPORTANT: The existing EnemyBase methods FireAtPlayer(), UpdateCombat(), MoveToEngagementPosition() are NOT virtual in EnemyBase.h. Do NOT try to override them with `virtual`. Instead, ZombieBase's Tick calls UpdateZombieCombat AFTER Super::Tick. The base UpdateCombat will harmlessly try to fire (weapon is null, FireAtPlayer returns early). The melee logic runs in UpdateZombieCombat separately.
