  - EnemyName = FText::FromString(TEXT("Zombie Explosif"))
  - if (HealthComp) HealthComp->SetMaxHealth(60.f)
  - MeleeDamage = 0.f (damage comes from explosion, not melee)

- PerformMeleeAttack() override:
  - Guard: if (bHasExploded) return;
  - Set bHasExploded = true
  - Apply radial damage: UGameplayStatics::ApplyRadialDamage(this, ExplosionDamage, GetActorLocation(), ExplosionRadius, nullptr, TArray<AActor*>(), this, GetController(), true, ECollisionChannel::ECC_Visibility)

    - The `true` parameter is bDoFullDamage (full damage regardless of distance within radius)
  - Call BP_OnExplode() for Blueprint VFX hook
  - Kill self: if (HealthComp) call UGameplayStatics::ApplyDamage(this, 9999.f, GetController(), this, nullptr)
    - This triggers the normal death flow: HealthComponent->HandleTakeAnyDamage -> OnDeath -> EnemyBase::HandleDeath -> OnEnemyDied.Broadcast (so wave spawner tracks the death correctly)

IMPORTANT: Do NOT call Destroy() directly. Use ApplyDamage to self so the death delegate chain fires properly and the wave spawner decrements its alive count.
