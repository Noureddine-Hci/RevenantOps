Create AZombieSpitter that overrides PerformMeleeAttack to spawn projectiles and overrides movement to maintain distance.

**ZombieSpitter.h:**
- `#pragma once`, include `ZombieBase.h`, include `ZombieSpitter.generated.h`
- Forward declare: class AZombieProjectile;
- `UCLASS(Blueprintable)` class AZombieSpitter : public AZombieBase
- Public constructor: `AZombieSpitter();`
- Protected:
  - `UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Zombie|Ranged")` TSubclassOf<AZombieProjectile> ProjectileClass;
  - `UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Zombie|Ranged")` float ProjectileDamage = 20.f
  - `UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Zombie|Ranged")` FName ProjectileSpawnSocket = FName("head"); — socket on skeleton to spawn projectile from (mouth area)
  - `virtual void PerformMeleeAttack() override;` — spawns projectile instead
  - `virtual void Tick(float DeltaTime) override;` — adds distance-keeping behavior

**ZombieSpitter.cpp:**
- Include `ZombieSpitter.h`, `ZombieProjectile.h`, `GameFramework/CharacterMovementComponent.h`, `HealthComponent.h`, `AIController.h`, `Kismet/GameplayStatics.h`
- Constructor AZombieSpitter::AZombieSpitter():
  - GetCharacterMovement()->MaxWalkSpeed = 250.f
  - MeleeRange = 1200.f  // IMPORTANT: this is the ATTACK range, not melee. Spitter "melees" (fires) when within 1200cm
  - MeleeAttackCooldown = 2.5f  // fires every 2.5 seconds
  - MeleeDamage = 0.f  // damage comes from projectile, not melee
  - IdealEngagementRange = 1000.f  // tries to stay at 1000cm from player
  - MaxEngagementRange = 1500.f
  - EnemyName = FText::FromString(TEXT("Zombie Cracheur"))
  - if (HealthComp) HealthComp->SetMaxHealth(100.f)
  - SightRange = 2500.f  // sees further than melee zombies

- Tick(float DeltaTime) override:
  - Call Super::Tick(DeltaTime) — this runs perception + UpdateZombieCombat from ZombieBase
  - THEN add distance-keeping logic:
  - if (AlertState == EEnemyAlertState::Alert && TargetPlayer):
    - float Distance = FVector::Dist(GetActorLocation(), TargetPlayer->GetActorLocation())
    - if (Distance < IdealEngagementRange * 0.6f):  // player is too close (< 600cm)
      - Retreat: calculate FVector AwayFromPlayer = (GetActorLocation() - TargetPlayer->GetActorLocation()).GetSafeNormal()
      - FVector RetreatTarget = GetActorLocation() + AwayFromPlayer * 400.f
      - AAIController* AIC = Cast<AAIController>(GetController())
      - if (AIC) AIC->MoveToLocation(RetreatTarget, 50.f)

- PerformMeleeAttack() override:
  - Guard: if (!TargetPlayer || !ProjectileClass) return
  - Determine spawn location: FVector SpawnLoc
    - Try socket: if (GetMesh() && GetMesh()->DoesSocketExist(ProjectileSpawnSocket)) SpawnLoc = GetMesh()->GetSocketLocation(ProjectileSpawnSocket)
    - Fallback: SpawnLoc = GetActorLocation() + GetActorForwardVector() * 50.f + FVector(0, 0, 60.f)
  - Calculate direction to player: FVector Direction = (TargetPlayer->GetActorLocation() - SpawnLoc).GetSafeNormal()
  - FRotator SpawnRot = Direction.Rotation()
  - FActorSpawnParameters SpawnParams; SpawnParams.Owner = this; SpawnParams.Instigator = this;
  - AZombieProjectile* Proj = GetWorld()->SpawnActor<AZombieProjectile>(ProjectileClass, SpawnLoc, SpawnRot, SpawnParams)
  - if (Proj) Proj->InitProjectile(ProjectileDamage, this)
  - Call BP_OnMeleeAttack() (inherited from ZombieBase, serves as "attack performed" hook)

NOTE: The ProjectileClass defaults to nullptr. The executor MUST note in the SUMMARY that a Blueprint subclass of AZombieProjectile needs to be created in the editor, OR the ZombieSpitter Blueprint must set ProjectileClass to AZombieProjectile. Alternatively, set a default in C++:
- In the constructor, if we want a C++ default: we can use ConstructorHelpers to find the class, but that requires a known asset path. Better to just leave it as a UPROPERTY that must be set in the Blueprint.
- The SUMMARY should note: "ZombieSpitter Blueprint must set ProjectileClass to BP_ZombieProjectile (a Blueprint of AZombieProjectile)"
